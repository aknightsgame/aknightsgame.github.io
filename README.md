# A Knight's Game

Mobile games built with Godot, published on iOS and Android.

## Games

### Block Drop Puzzle
A hyper-casual block puzzle game. Drag and drop pieces onto an 8×8 grid to clear rows and columns — simple to learn, hard to put down.

- [Privacy Policy](https://aknightsgame.github.io/block-drop-puzzle/privacy-policy.html)

### Taxi Dash
A top-down taxi game: pick up fares, choose your own route across the city and earn your way to new districts and cabs.

- [Privacy Policy](https://aknightsgame.github.io/taxi-dash/privacy-policy.html)
